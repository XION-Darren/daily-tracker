# v1.1.0

- 含 v1.0.3 全部功能
- 新增云同步（GitHub Gist）：打开页面自动拉取云端数据并合并；每次改动 3 秒后自动推送；支持手动拉取/推送；本地 localStorage 为主存储，云端为跨设备同步副本
- 新增「⚙️ 设置与数据」折叠面板（置于今日记录底部，默认收起不碍眼）：内含本地数据管理（导出/导入）与云同步（Gist ID + Token 配置）
- 拉取请求支持携带 Token，兼容私密（Secret）Gist
- 启动时检测 Gist 配置状态并提示；静默拉取失败时给出明确原因提示（网络错误/未配置）
- 云同步配置（Gist ID + Token）保存在本设备浏览器 localStorage，非一次性，刷新后保留
