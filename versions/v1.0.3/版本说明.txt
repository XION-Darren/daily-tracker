# v1.0.3

- 含 v1.0.2 全部功能
- 分类重构为两级结构：
  工作：求职 / 研究 / 其它
  运动：快走 / 力量 / 其它
  学习：AI / 能源 / 创业 / 理财 / 其它
  生活：美食 / 家务 / 逛街 / 其它
  休息：睡觉 / 娱乐 / 其它
  带娃：学习 / 娱乐 / 其它
- 表单改为一级分类 + 二级子类联动下拉
- 状态栏改为 4 项（加小图标）：行动项、睡觉时长（rest→sleep）、活跃域（运动/学习/生活/带娃中时长最高类，动态显示）、工作时长（仅工作大类）
- 「有效工作 8 小时」进度条按纯工作时长（工作大类）计算
- 今日记录折叠：默认显示 7 项，底部虚线按钮「展开全部（N 项）」/「收起 ▲」
- 滚轮时间选择器改为智能步进：普通鼠标一格 = 1 个单位，平滑滚轮/触控板按累计偏移合并，兼容 deltaMode 行/页模式
- 旧数据兼容：cook→生活·美食，other→休息·其它 等映射
