# v2.0.0

## 本次更新（V2 大版本）

### 云同步增强
- 页面从后台切回前台时自动拉取云端数据，多设备同步更及时
- 无需手动刷新也能看到另一台设备的新记录

### 工作分类调整
- 「工作」二级菜单第一顺位由「求职」改为「研究」，符合当前重心

### 手机端优化
- 修复手机竖屏下表单二级下拉菜单溢出屏幕的问题
- 小屏输入框、下拉框自动压缩，不再超出界面

### 新增 PWA（安装为 APP）
- 支持用 Edge 手机版「添加到主屏幕 / 安装应用」
- 安装后图标显示在桌面，全屏运行，像原生 APP
- 离线也能打开（Service Worker 缓存）

### 新 LOGO
- 苹果扁平化风格图标（紫色渐变 + 简洁符号）
- 适配手机桌面图标（192 / 512 双尺寸）

## 使用提示
- 手机 Edge：打开网址 → 菜单 → 「添加到手机」/「安装应用」即可装到桌面
